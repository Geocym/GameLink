# GameLink 0.2.3
Build GameLink.sln with .NET 10 on Windows. Preserve your 0.2.2.1 folder. Existing settings are reused.

New achievement arguments: achievementsTotal, achievementsUnlocked, achievementsRemaining, achievementCompletionPercentage, isGameCompleted, isFirstAchievement, achievementMetadataSource, isHiddenAchievement (when available), achievementIconLocked (when available), gameSessionDurationSeconds, gameStoreUrl, gameHeaderImage. Progress reflects the entire observed cache snapshot, not intermediate states if several achievements arrive together.
Online metadata defaults on; disable in Settings. Public rarity endpoint and icon download each have a two-second HTTP timeout; unknown values are omitted. Rarity cached in memory for one hour (five minutes on failure). Artwork cached in %AppData%/GameLink/artwork. Rarity thresholds U/R/E/L default to 25/10/5/1 percent. Game header URL is constructed, not verified. No gameIcon yet.
New events: achievement.game_completed (observed transition to full completion), game.session_summary (on exit, includes observed duration, sessionAchievementsUnlocked, sessionRareAchievementsUnlocked, and latest available progress). Rare count includes only known rare unlocks. Summary excludes late unlocks after exit; those still produce achievement events. Session duration begins when GameLink first observes the game. No persistent event queue yet.

Test: launch, check no historical alerts, unlock a new achievement, inspect all args and artwork file, exit and inspect summary. Repeat with online metadata disabled. Verify specific routes (achievement completion uses achievement action, summary uses lifecycle action). Test 100% completion if convenient. Verify no recurring reconnects. Windows compile and live HTTP verification remain outstanding.
