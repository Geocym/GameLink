# v0.2.9.2 validation

- Build the solution and run Publish-Windows.ps1 on Windows.
- Extract the generated ZIP on a clean x64 Windows machine without .NET Desktop runtime; verify launch and SQLite history.
- With a harmless Streamer.bot action, start and stop a Steam game whose header is cached. Check game.started, game.stopped and game.session_summary for gameHeaderImage and gameHeaderLocalPath, both flattened and in eventJson.
- Repeat with a game whose header is not cached, with online metadata enabled. Verify the header is downloaded if reachable and the local path points to a valid image. The delivery pipeline allows up to two seconds per CDN attempt; failures do not prevent delivery. Failed attempts are throttled per game for two minutes.
- Disable online metadata and repeat with a missing header: remote URL remains, local path is omitted and no header download is initiated by the queue.
- Test achievement events, recovered summaries, replay and portable migration; local paths should reflect active storage. Non-Steam process events must not receive Steam artwork.
- Confirm existing history, settings, replay and startup behaviour remain intact.
