# GameLink 0.2.5.1 UI preview
Build in Visual Studio with .NET 10 Windows Desktop. Keep 0.2.5 as fallback.
- Open Achievements: one artwork card per matching game, progress once per game. Revolution Idle should show 71/770 if unchanged.
- Click a game; scroll through hundreds of achievements, search and filter. Back returns to game library. Global search narrows game cards; click to see matching achievements.
- Click a concealed achievement to reveal it; Reveal hidden toggles all in the selected game. Back clears reveal state. Click visible achievement to inspect/copy.
- Check artwork with online metadata enabled and disabled. Cached images remain usable offline. Missing images have placeholders.
- Dashboard: check current game cards, session clock, progress, recent activity and recovered labels. Synthetic tests are excluded from dashboard but remain in event history.
- Check game launch/exit, real achievement, queue and Streamer.bot routing regression.
Limitations: light palette only; dashboard statistics are bounded current-process history, not historical totals. No separate latest achievement showcase or persistent statistics yet. Artwork loads sequentially for visible cards. Custom cards are mouse-driven; keyboard/accessibility refinement pending. Windows build and visual testing not performed in Linux.
